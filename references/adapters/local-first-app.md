# 适配地图：本地优先应用

> 用途：这一类项目的工程协议有稳定共性，但**结论不通用**。识别出这些共性后，按项目的实际结构重新登记命令、证据与门禁。

## 1. 识别特征

| 特征 | 观察点 |
| :--- | :--- |
| 单机运行 | 启动方式是本地进程，不是远端集群 |
| 数据本地 | 存储是本地文件或嵌入式数据库，不是远端服务 |
| 无多租户 | 不区分组织与账号隔离，凭据由使用者自持 |
| 交付形态 | 源码分发或本地安装，不是持续部署 |

## 2. 稳定领域地图

| 领域 | 常见切片 | 常见耦合点 |
| :--- | :--- | :--- |
| 内容模型 | 作品、章节、结构节点 | 版本与迁移档位 |
| 生成能力 | 模型网关、提示词装配 | 密钥管理与出站校验 |
| 编辑体验 | 编辑器内核、行内差异 | 保存与并发 |
| 本地存储 | 迁移、备份、快照 | 升级前快照与回滚 |
| 外部集成 | 本地协议客户端 | 子进程与攻击面 |

> 以上只描述「一般会有哪些切片」，不描述任何具体项目的数量与命名。

## 3. 这类项目特有的证据口径

| 通用方法 | 本地应用里的调整 |
| :--- | :--- |
| 接口黑盒 | 除了接口，还要验证「本地进程是否只监听回环」 |
| 端到端 | 必须覆盖「关掉外部服务后是否诚实降级」，不能只测联网路径 |
| 数据安全 | 备份与迁移快照本身就是交付物；没有快照的迁移不算完成 |
| 凭据 | 凭据不得出现在日志与错误信息；不得随包发布 |
| 可观测性 | 多数没有远端监控，本地日志与错误文件是唯一现场 |

## 4. 适配检查

- [ ] 启动方式、监听地址、默认端口是否登记
- [ ] 数据库迁移入口与回滚方式是否登记（禁止绕过迁移守卫）
- [ ] 离线路径是否可运行，且降级有如实来源标记
- [ ] 备份与快照是否在验收范围内
- [ ] 凭据读取路径是否被封禁，日志是否可能泄露

## 5. 不适用

- 多租户隔离、配额与计费：本地单用户形态下不存在，不要生造。
- 持续部署与灰度：交付形态不同，相关方法不适用。
- 生产监控告警：多数项目没有，替代方案是本地日志与升级前自检。
