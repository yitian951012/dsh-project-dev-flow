# 待裁决项：{{project.name}}

> 用法：本表只放**必须人拍板**的事。凡是「再查一次就能定」的，归研究任务，不占裁决位。
> 每条必须能回答：谁在等、等到什么时候、不决的后果是什么。

## 1. 条目模板

| 字段 | 值 |
| :--- | :--- |
| 编号 | 待填（全局唯一） |
| 状态 | 待补证 / 待裁决 / 已裁决 / 已关闭 |
| 一句话问题 | 待填 |
| 为什么必须人决定 | 价值取舍 / 范围 / 预算 / 风险接受 |
| 决策人 | {{role:approver}} |
| 提出日期 | {{date:today}} |
| 截止条件 | 日期或触发事件 |
| 阻塞对象 | 哪些工作正被它挡住 |
| 关联决策 | 待填 |

## 2. 取证结论（专家可填）

| 问题 | 已有证据 | 证据强度（强 / 弱 / 无） | 还缺什么 |
| :--- | :--- | :---: | :--- |
| 待填 | 待填 | 待填 | 待填 |

> 取证只能收敛「事实」，不能收敛「价值」。证据已足够但仍在队列里的，问题应改为「选 A 还是选 B」。

## 3. 选项与后果

| 选项 | 立刻要做什么 | 后续代价 | 最坏情况 | 可逆性 |
| :--- | :--- | :--- | :--- | :--- |
| 立即做 | 待填 | 待填 | 待填 | 高 / 中 / 低 |
| 推迟做 | 待填 | 待填 | 待填 | 高 / 中 / 低 |
| 不做 | 待填 | 待填 | 待填 | 不可逆 |

## 4. 裁决与关闭

| 字段 | 值 |
| :--- | :--- |
| 裁决结果 | 待 {{role:approver}} 填写 |
| 裁决日期 | 待填 |
| 转成决策编号 | 待填（若进入实施） |
| 关闭理由 | 待填 |

## 5. 队列健康检查

- [ ] 每条都指明决策人，没有「等大家」
- [ ] 每条都有截止条件，不靠记忆
- [ ] 已裁决条目已移出队列，不留残影
- [ ] 证据不足的条目写明「还缺什么」，而不是空转
- [ ] 队列里没有把同一个问题拆成多条重复项
