# WBS 验收拆解：{{project.name}}

> 用法：一行 = 一个可独立判定的能力。判据必须是**别人照着能复现**的句子，不是形容词。
> 两个维度分开写：**证据类型** = 自动 / 人工；**状态** = 未实现 / 已实现未验证 / 已验证。不允许出现「大概做完了」。

## 1. 拆解原则

1. **一行动作一个判据**。一句话里有两个「并且」，就拆成两行。
2. **判据写结果不写过程**。「点击保存后重新打开仍在」比「实现了保存」可判定。
3. **证据类型先声明**。写不出自动断言的，如实标「仅人工可证」，不要伪装成自动。
4. **依赖显式化**。同一行的前置条件写进备注，不靠上下文记忆。

> 未实现项必须能回答「什么条件下会重新做」，否则它会在无人知晓处永远消失。

## 5. 验收行自查

- [ ] 判据能被第三方复现，不依赖作者记忆
- [ ] 每行只测一件事
- [ ] 「仅人工可证」的行数量没有明显多于自动行（否则是测试欠债）
- [ ] 证据位置指向同一 {{commit:head}}，不跨提交拼接
- [ ] 没有把「代码存在」当作「能力可用」
