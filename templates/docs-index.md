# 文档索引（唯一入口）

> 本索引是文档的**唯一分类与定位处**。规则：这里只写「有哪些文档、什么性质、讲什么」，不写任何进度、规模、覆盖率、版本号数字。
> 数字只有一个去处：状态看板的事实源小节，或当场命令输出。

## 性质说明

| 性质 | 含义 | 能否作依据 |
| :--- | :--- | :--- |
| 活 | 描述当前规则、契约与状态 | 可以 |
| 史 | 某一时点的快照或留痕 | 不可以，只代表当时 |
| 档 | 审计归档原文，仅证据链 | 不可以 |

## 索引表

| 文档 | 性质 | 一句话定位 | owner | 复核到期 |
| :--- | :---: | :--- | :---: | :--- |
| [示例文档]({{doc:index}}) | 活 | 讲什么、给谁看 | {{role:owner}} | 待填 |
| 待填 | 史 | 哪一时点、记了什么 | {{role:owner}} | 待填 |

## 维护约定

1. **新增文档 = 加索引 + 加登记**。两件都做才算完成；只做一件视为漂移。
2. **改性质 = 改审查面**。升为活即接受日常校验；降为史即退出校验，并逐条标注时点。
3. **合并只换宿主**。原文不删字，旧文件名留在正文里作链接文字，并在登记册写旧到新的映射。
4. **索引自身不参与覆盖统计**，避免它把自己算成条目。
5. **索引里出现数字即缺陷**，按缺陷处理，不按风格建议处理。

## 索引自检

- [ ] 每份受管文档在表中有且只有一行
- [ ] 每行都有性质与定位，没有空列
- [ ] 复核到期日不超过十二个月
- [ ] 索引内没有复制任何进度数字
- [ ] 断链为零（链接目标真实存在）

> 自检不通过时，先修索引，再写正文；否则后写的正文会引用一个不存在的定位。
