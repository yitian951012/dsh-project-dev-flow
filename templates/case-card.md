# 案例卡：标题

> 用法：案例回答的是「当时为什么这样选、代价是什么」，不是「正确做法是什么」。
> 没有失败过程的案例不收：只写成功的案例无法指导下一次判断。

## 来源与时间（不计入七段编号）

| 字段 | 值 |
| :--- | :--- |
| 来源项目 | 来源项目（下称 P），待填实际日期（脱敏，原文不随包发布） |
| 事项 | 待填 |
| 时点 | 待填（必须写具体日期） |
| 证据可获得性 | bundled / external / unavailable（三态含义见 `evidence/README.md`） |
| 脱敏级别 | 已脱敏 / 待脱敏 |
| 整理人 | {{role:owner}} |
