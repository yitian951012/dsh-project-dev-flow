# 设计定型与不变量守卫

> 用途：把设计定型变成「边界 + 契约 + 回滚路径 + 可失败断言」，而不是一份读起来很完整的文档。

## 1. 适用与不适用

| 适用 | 不适用 |
| :--- | :--- |
| 一次改动要定边界、契约、迁移档位与回滚 | 纯文案、纯注释、纯格式改动 |
| 新增或修改一条结构约束（守卫 / 棘轮） | 该约束已被既有守卫覆盖，只是换了实现位置 |
| 判断某条测试算不算守卫、是否假绿 | 判断功能是否可用（那需要当场证据） |
| 要把「有清单」与「全覆盖」分开 | 需要逐条业务用例清单（那是测试设计） |

边界：本文件管「约束怎么被守住」，不管「这次改动值不值得做」。

## 2. 核心判断

1. **不变量是「破坏后不报错」的那类约束。** 功能坏了守卫依然绿，所以「测试全绿」推不出「约束被守住」。这类约束必须集中登记，否则它会安静地失效。
2. **每条不变量写四件事：守什么、谁在守、假绿风险在哪、有没有做过反向验证。** 缺第四项就是「未验证的守卫」——它可能是真的，也可能永远返回空。
3. **没有控制组的守卫等价于空扫描器。** 必须构造必然违规的样本，并证明它被抓到。只会通过的检查器不是检查器。
4. **结构约束优先做成机器能判的形式。** 编译期约束 > 静态扫描 > 行为断言 > 人工核对。人工项可以存在，但必须显式标注，不得混进自动判据。
5. **「有实现」不等于「生效」。** 组件写好没挂载、接口写好没人调用、钩子写好没接上，界面都不报错。凡涉及接线，断言必须落到「真实调用点 + 真实入口 + 反向证明」三件套。
6. **口径必须唯一。** 同一度量（宽度、字数、计数、统计规则）只允许一套定义。两套并存时，按其中一套施工就会做出另一套已作废的结果。
7. **棘轮只许变好。** 已收敛的基线只能下降或持平；「新增一条又删一条旧的」会把总数抹平，所以要看逐项核对而不是汇总。
8. **白名单要双向校验。** 已登记的例外一旦不再出现也应报错，否则白名单会退化成永久豁免。
9. **改判据就是改尺子。** 调阈值、调基线、改白名单、缩跳过范围属于守卫资产变更：须授权、须留「改坏 → 变红 → 改回」的记录，否则当次绿灯作废。
10. **诚实登记空缺。** 该守而没守的要写进缺口表，并给建议的守护方式。把空缺写成空缺，才让「有清单」不等于「全覆盖」这句话成立。
11. **决策记录的状态与落地要分开写。** 提议 / 已接受 / 被取代是三件事；「已接受但只落了一层」必须在记录里写明落地边界，否则验收时会读成已完成。

## 3. 可执行步骤

1. **画变化面。** 列出这次改动碰到的边界：模块之间、层之间、客户端与服务端之间、数据结构、对外契约。
   产出：边界清单，每处一句「谁可以调谁」。
2. **写契约。** 每条边界给出唯一入口与允许的形状；例外登记理由，而不是就地放宽。
   产出：契约条目（入口 / 形状 / 例外及理由）。
3. **分型。** 给每条约束选类型：行为正确性 / 结构完整性 / 接线是否断 / 口径是否唯一 / 降级是否诚实。类型决定守护方式。
   产出：约束 → 类型映射。
4. **选守护方式。** 能编译期拦住的不靠扫描；能静态判的不靠行为测试；只能用行为测试时，给出最小可判的输入输出。
   产出：每条约束的守护手段与理由。
5. **写控制组。** 每条扫描类守卫都要有必然违规样本（必须被抓到）和一个合法样本（必须不误报）。
   产出：正反两组的样本与断言。
6. **做反向验证。** 把被守护的代码按原始状态整体改坏，确认变红；再改回，确认变绿。只回退一半（例：撤了样式却留下容器规则）会造成假绿。
   产出：一次「改坏 → 红 → 改回 → 绿」的记录。
7. **登记。** 在不变量清单里写守什么、谁在守、假绿风险点、反向验证记录；没有反向验证的写「未验证」，不许留空。
   产出：清单行；空白即视为缺陷。
8. **定棘轮与白名单。** 基线只降不增；白名单逐条写理由与复核条件，并加「条目过期即报错」的校验。
   产出：棘轮基线 + 白名单条目（含理由、复核条件）。
9. **记缺口。** 该守未守的逐条进缺口表，写清建议的守护方式，不要把缺口藏进一句「已知限制」。
   产出：缺口表行（约束 / 现状 / 建议守卫）。
10. **写决策记录。** 背景与失败模式、候选方案对比（正确性 / 成本 / 风险 / 可回滚）、建议与拍板人、影响面、回滚路径。
   产出：决策记录，状态与落地边界分列。

## 4. 常见失败

| 失败 | 表现 | 纠正 |
| :--- | :--- | :--- |
| 假绿扫描器 | 扫描器返回空，全部通过 | 加控制组，证明它会红 |
| 子串污染 | 断言「不含 A」，却命中 A 的变体 | 用边界匹配或词法判定 |
| 注释污染 | 注释里的旧词造成假红或假绿 | 判定前先剥离注释 |
| 双写并存 | 抽了共用件，旧实现还在跑 | 旧路径加守卫禁止再出现 |
| 文件存在即生效 | 只断言导入或文件存在 | 断言真实调用点与入口 |
| 棘轮被抹平 | 新增一条、删一条，总数不变 | 逐项核对，不只看汇总 |
| 白名单永久化 | 例外登记后永不复查 | 双向校验，过期即报错 |
| 口径两套 | 同一度量两处定义 | 收敛为一份，另一份改引用 |
| 变异假绿 | 回退不彻底就宣布守卫有效 | 按原始状态整体回退 |
| 未验证留空 | 反向验证列空白仍算完成 | 写「未验证」并降级 |
| 新机制本身无守卫 | 检查脚本坏了没人发现 | 给检查脚本加自检样本 |
| 决策只写结论 | 没有失败模式与代价对比 | 补场景、后果、方案对比与可回滚性 |
