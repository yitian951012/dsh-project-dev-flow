# 事实源分权与文档生命周期

> 用途：判断「这条结论现在还算不算数」。本文件只给判断与协议，不给任何项目的数字、命令或路径。

## 1. 适用与不适用

| 适用 | 不适用 |
| :--- | :--- |
| 要判断某条结论该信谁、哪份文档能作依据 | 项目已规定权威层级，只需按其执行 |
| 同一事实在多份文档里数值不同或性质不同 | 需要当场实测数字（属验证与验收） |
| 文档要新增、改名、合并、升格或降级 | 只改单篇措辞，不动性质与归属 |
| 要判断某条历史结论能否用于今天 | 需要全文检索定位（属检索任务） |

边界：本文件管「信谁」，不管「对不对」。内容是否正确，回到该维度自己的方法与当场实测。

## 2. 核心判断

1. **一个事实维度只有一个当前源。** 进度数字、范围决策、验收判据、结构约束、历史留痕各自归口；同一维度不得有两份文档并列维护当前值。
2. **分权不等于分散。** 入口文档只负责定位（有哪些文档、各是什么性质），不承载任何数值。索引一旦开始抄数字，就凭空产生了第二个当前源。
3. **性质三分：活 / 史 / 档。** 活＝描述当前规则与契约，可作依据；史＝只对当时成立，不得当作现状；档＝仅作证据链，不作任何判断依据。性质是判定开关，不是礼貌标签。
4. **改性质等于改审查面。** 一份文档从活降为史，意味着它退出日常校验；从史升为活，意味着它的旧表述立刻进入被追责范围。所以改性质必须与登记同步，并逐条标注时点。
5. **结论绑载体。** 任何「已达成 / 已验证 / 已修复」都要绑到可复现的载体与时间点。脱离载体后，它自动降级为背景资料，而不是仍然有效的现状。
6. **引用要带时态。** 引用活文档写「当前」；引用史文档必须写明「当时 + 日期」，不得用现在时口吻复述。
7. **历史不删除，只换层。** 历史的价值是解释「当时为什么这样做」；删掉它，下一次会重犯同一个错误。合并不删字，只换宿主并登记旧名到新宿主的映射。
8. **性质未声明者按活处理。** 默认从严：没有明确标注为史或档的内容，一律按当前有效对待并纳入校验。宁可让旧内容被迫显形，也不让它在沉默中过期。
9. **检查器绿灯不等于内容正确。** 自动检查只校验它能匹配到的模式；绿灯证明的是「它没抓到」，不是「这里对」。读到绿灯就停手，是最常见的误判来源。
10. **冲突不投票。** 两处数值冲突时不取最新、不取最大、不取平均：先判是否同一维度，同维度只留一份并显式登记「以谁为准」，跨维度则各自成立并交叉引用。

## 3. 可执行步骤

1. **列维度。** 把当下要判断的事实分成五类：进度与规模、范围决策、验收判据、结构约束、历史留痕。
   产出：一张「维度 → 当前源」对照表，每行一句判据。
2. **定唯一源。** 每个维度指定一份当前源，并列出「禁止并列维护」清单：哪些文档只许引用、不许复制数值。
   产出：源清单 + 禁止复制清单。找不到源时先补源，不先补数字。
3. **标性质与定位。** 每份文档给一个性质（活 / 史 / 档）和一句话定位，定位写「讲了什么、给谁看」。
   产出：索引里的性质列与定位句；同一条目只在一处登记。
4. **扫重复。** 同一事实是否出现两处以上？出现即视为缺陷：保留唯一源的值，其余改成引用；无处可引就删掉复述。
   产出：重复事实清单与处置（改引用 / 删句 / 合并）。
5. **查载体。** 逐条检查结论是否带复现入口、时间点、范围边界。缺载体的一律改写为「当时曾达成」或「未验证」。
   产出：无载体结论清单。
6. **决冲突。** 按顺序走：先判是否同维度；不是，则各自成立并互指；是，则只留一份，另一份标过期并写明以谁为准。
   产出：冲突登记行（含两处位置、判定、裁决依据）。
7. **登记变更。** 新增、改名、合并、升格、降级都做两件事：改索引里的性质与定位，改登记册里的日期、依据、旧名到新名映射。
   产出：索引与登记册同步；只改一件即视为漂移。
8. **定期复核。** 给每份活文档一个复核到期日；到期未复核即视为过期，先降级再改内容。
   产出：复核队列；不得用「更新日期」代替复核。
9. **给判定结论。** 一句话回答「该信谁 + 依据 + 剩余缺口」。缺口存在时写「未验证」，不写「基本可信」。
   产出：可被他人复核的判定句。

## 4. 常见失败

| 失败 | 表现 | 纠正 |
| :--- | :--- | :--- |
| 索引变第二事实源 | 索引里出现进度数字，且与源不一致 | 索引只留定位，数字一律回源 |
| 性质双重归类 | 同一份文档在一处算活、另一处算史 | 性质只在一处登记，别处只引用 |
| 以最新为准 | 两处冲突，选了日期较新的那份 | 按维度定源，冲突显式登记 |
| 绿灯即正确 | 检查器不告警就认为内容可信 | 追问「我的写法能被它的规则匹配到吗」 |
| 历史当现状 | 用带日期的旧结论描述今天 | 引用历史必须写明时点 |
| 合并丢字 | 合并后旧内容被压缩或删句 | 原文保留，旧文件名留作链接文字 |
| 未声明性质 | 新文档既不标活也不标史 | 默认按活处理并纳入校验 |
| 引用无载体 | 「已验证」后面没有可复现入口 | 补载体，或降级为「未验证」 |
| 摘要抄数字 | 为了让读者方便，把数值复制进多处 | 改为引用；方便不是第二源的理由 |
| 只改索引不登记 | 扫描面变了，登记册不知情 | 两件事一起做，缺一即漂移 |
| 过期靠记忆 | 复核日期早已过去，没人处理 | 到期即降级，不靠人主动想起 |
| 结论无时态 | 「功能已完成」这类现在时断言 | 改写为「某时点已达成」并留证据位 |
